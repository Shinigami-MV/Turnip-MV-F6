# Installation Guide - Turnip-MV-F6

## Requirements

- POCO F6 (or compatible Adreno 735 device)
- Winlator Ludashi

## Steps

1. Download the latest `.zip` from [Releases](https://github.com/Shinigami-MV/Turnip-MV-F6/releases).
2. Open Winlator Ludashi.
3. Go to **Driver Manager** / **AdrenoTools**.
4. Import the downloaded ZIP.
5. Select the driver **Turnip MV F6**.
6. Restart the container / game.

## Backup

Always keep a known-good driver as backup before testing experimental builds.
